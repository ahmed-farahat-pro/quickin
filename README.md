# QuickIn — mobile apps

The iOS and Android clients for **QuickIn**, a boutique vacation-rental platform
for Egypt. Both apps talk to the `quickin-backend` API over a shared Neon
Postgres database; the website and the `/ops` admin console live in
`quickin-frontend`.

> This repo used to also carry a copy of the website under `src/`. It was a stale
> fork of `quickin-frontend` and was removed on 2026-08-19 — the web app is
> maintained in its own repo.

## Layout

| Path | What it is |
| --- | --- |
| `mobile/ios` | SwiftUI app. Project generated by XcodeGen from `project.yml`. |
| `mobile/android` | Kotlin / Jetpack Compose app, Gradle KTS. |
| `local-backend` | Local Postgres schema, seed and a small standalone admin tool for development. |
| `docs` | Architecture and platform notes. Several predate the web split — see `CLAUDE.md`. |
| `.github/workflows` | TestFlight upload (iOS) and APK publish (Android). |

## Stack

- **iOS** — Swift 5.9 / SwiftUI, XcodeGen, Firebase (push only)
- **Android** — Kotlin, Jetpack Compose, Material 3
- **API** — `https://quickin-backend.vercel.app` (Next.js 16 route handlers)
- **Database** — Neon Postgres, shared with the website
- **i18n** — English, Arabic (RTL), French, Spanish on both platforms

## Features

- Browse and filter boutique stays, with map view and wishlists
- Booking requests, host approval, and reservation management
- **Instapay payments** — the guest transfers and uploads a screenshot, the host
  reviews it. There is no card gateway
- Host tools: create and edit listings, manage availability and pricing, respond
  to booking requests
- ID verification and host applications, reviewed by staff in `/ops`
- Guest ⇄ host chat with an off-platform-contact content guard
- Push notifications, stay passes (QR + Apple Wallet), and host stay guides

## Running the apps

```bash
cd mobile/ios && xcodegen generate && open QuickIn.xcodeproj
```

```bash
cd mobile/android && ./gradlew installDebug
```

Both apps hit the deployed `quickin-backend` by default, so they run against
real data with no local server. To point a debug build at a local dev server,
set `Config.apiBaseURL` to `http://127.0.0.1:3000` on iOS, or pass
`-PDEV_API_BASE_URL=http://10.0.2.2:3000` to Gradle on Android. Full setup,
including the local database, is in `SETUP.md`. Signing and key creation are in
`CREATE-KEYS.md` and `OAUTH-SETUP.md`.
